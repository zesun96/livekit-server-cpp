# Language bindings

- [Java 17 SDK](java/README.md): JNI bridge, all server service methods, access-token signing,
  webhook verification, dependency-free JSON model wrappers, examples and offline tests.
- [Ruby SDK](ruby/README.md): Fiddle/C ABI bridge, all server services, token grants, webhook
  verification, Hash/JSON models, gem packaging, examples and offline tests.
